# Demo and evaluation fixtures

아직 자료는 없고 디렉터리만 있다. 실존 환자·음성·문서를 넣지 않는다.

- `seed`: 환자 1명, 계정 3개, 같은 진료과 이전 기록·예정 진료, 비교용 다른 과 기록·질문.
- `audio`: 준비한 가상 진료 음성. 저장된 전사는 expected에서 대체 결과로 구분.
- `documents`: 모의 약봉투·처방전·흐린 문서.
- `expected`: 정답 라벨·예상 불일치·검증된 저장 결과. 실제 평가 분모를 명시.

보호자 A의 지난 진료를 B가 이어받는 인물 이름·동행 이력·등급을 통일한다.
일정만·동행·전체 내용 검증은 일반 보호자의 등급을 바꿔 수행한다.
큰 바이너리를 넣을 때는 Git 추적 방식과 공유 위치를 먼저 정한다.
