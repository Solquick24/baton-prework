# Demo plan

현재 시드·데모 앱은 없다. 아래는 향후 준비할 시나리오다.

1. 환자·대표 보호자 A·일반 보호자 B 계정과 내과 이전 두 기록·예정 진료를 준비한다.
2. A의 지난 동행 기록을 B가 이번 브리핑에서 이어받는다.
3. B의 질문 3개·통합 결과·근거·다른 과 제외를 보여준다.
4. 가상 음성과 메모로 정리하고 메모·약봉투 불일치를 확인한다.
5. 검증된 요약이 자동 공유되고 다음 브리핑에 확인 항목이 유지됨을 보여준다.
6. B의 등급을 바꿔 일정만·동행·전체 내용 응답을 비교한다.
7. 가장 큰 글씨·고대비와 정적 병원 안내를 보여준다.

실제 호출·저장된 대체 결과·시드·정적 화면을 구분해 발표한다.
약 이름·복용 시간 불일치 등은 모두 모의 자료로 준비한다.
자료 수와 정답 라벨·평가 분모를 통일하고 2회 연속 완주 후 결과를 기록한다.
