# MVP 결정 기록

2026-10-09 요청에 따라 구조 생성용 기본안을 기록한다.
기획안의 과거 합의를 수정했다는 의미가 아니며, 정책 변경 시 명세·계획에 함께 반영한다.

| 항목 | 기본안 | 근거·주의 |
|---|---|---|
| 저장소 | npm workspaces 3개 | 제안한 monorepo 구조를 사용자가 수락 |
| 언어·실행 환경 | TypeScript / Node 22.12+ / 22.x / npm 10.x | 설치된 환경 활용; 라이브러리 버전은 구현 시 고정 |
| 프론트·백엔드 | React/Vite, Lambda/SAM | 이전 구조 제안; 아직 코드·AWS 자원 없음 |
| 공유 시점 | 검증된 정리 저장 후 자동 공유 | 기획안 확정 결정 우선; 미해결 불일치는 표시 유지 |
| 등급 | schedule/accompaniment/full | 확정 3단계와 제안 세부 범위를 명세 표로 구체화 |
| 동행의 원문 | 허용 정보의 안전한 인용만 | 전체 문서·녹음·진단명·수치 누출 방지 |
| 일정만 | 진료일·예약 일정·위치 | 질문·브리핑·진료과 제외 |
| 음성 | 1단계 가상 파일 변환, 2단계 직접 녹음 | F13 단계 구분 우선 |
| AI 정책 | 서울 리전 기본, 프롬프트·출력 검증 | 교차 리전 Guardrails 기본안 제외; 실제 호출·차단 시험 필요 |
| 지도 | 정적 위치·약도부터 | 외부 지도 제공자·계정 연결은 구현 시 확인 |
| 이번 생성 범위 | 문서·폴더·JSON 설정·환경 변수 예시 | 앱 코드·테스트 코드·배포용 template 제외 |

실제 건강정보·녹음·공유·위임의 처리 요건과 교차 리전 정책 변경은 실제 사용 전 확인한다.
